মারকাযুল কুরআন ইসলামিয়া মাদরাসা — ওয়েবসাইট প্রাথমিক সংস্করণ

ফাইল:
- index.html : ওয়েবসাইটের মূল পৃষ্ঠা
- assets/madrasa-logo.jpg : আপনার দেওয়া মাদরাসার লোগো

পরীক্ষা:
index.html ফাইলটি Chrome-এ খুললেই ওয়েবসাইট দেখা যাবে। ইন্টারনেট থাকলে বাংলা ফন্ট ও হিরো ব্যাকগ্রাউন্ড ছবি লোড হবে।

গুরুত্বপূর্ণ:
এটি একটি প্রাথমিক প্রকাশযোগ্য ডিজাইন/ফ্রন্টএন্ড। অনলাইন ভর্তি আবেদন এখনো কোনো ডাটাবেজে জমা হয় না; নির্দিষ্ট Google Form বা ব্যাকএন্ড সংযুক্ত করতে হবে। অনলাইন ফলাফলও চালু করতে শিক্ষার্থীদের অনুমোদিত ফলাফল-ডেটা ও অনুসন্ধান ব্যবস্থা যুক্ত করতে হবে। অ্যাডমিন লগইন, শিক্ষক-তথ্য, অভিভাবকদের প্রকৃত মতামত, ফেসবুক লিংক এবং দান/পেমেন্ট তথ্য এখনো যোগ করা হয়নি। ডেমো/অনুমানভিত্তিক তথ্য প্রকাশের আগে যাচাই করুন।

ফ্রি হোস্টিং:
GitHub Pages ব্যবহার করা যায়। GitHub-এ একটি public repository তৈরি করে এই ফোল্ডারের সব ফাইল আপলোড করুন। Repository Settings > Pages > Deploy from a branch > main / root নির্বাচন করুন। প্রকাশিত URL GitHub Pages দেখাবে।
